# Tick brand assets

The Tick currency sign is an **hourglass** — drawn as a single stroked glyph so it can sit in front of an
amount like `$` or `€`: ⧖ 86,400.

| File | Use |
|---|---|
| `tick-sign.svg` | The bare currency sign. Inherits `currentColor` (set `color` in CSS). |
| `tick-sign-on-lime.svg` | App icon / avatar, lime tile. |
| `tick-sign-on-ink.svg` | App icon / avatar, dark tile. |
| `tick-lockup.svg` | Sign + "tick" wordmark. |
| `sheet.html` | Preview of the whole set. |
| `concepts.html` | The three concepts explored (A hourglass, B sand coin, C struck T). |

Colours: lime `#C9F26B`, ink `#16210F`. Stroke 6 on a 64 grid, round caps and joins.
