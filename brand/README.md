# Tons brand assets

The currency is **Tons**. Its sign is a **slanted-strike T**: a T struck by a slanted bar through the stem, with the little seconds pip. It is close in spirit to the Mongolian tögrög (₮), but the slash and the pip make it its own shape. It is drawn as a stroked glyph, so it sits in front of an amount like `$` or `€`.

| File | Use |
|---|---|
| `ton-sign.svg` | The bare currency sign. Inherits `currentColor` (set `color` in CSS). Used next to amounts. |
| `ton-mark-on-lime.svg` | App icon / avatar on lime. |
| `ton-mark-on-ink.svg` | Same on the dark tile. |
| `ton-lockup.svg` | Mark + the "tons" wordmark. |
| `concepts/` | The sign explorations: two rounds of weight shapes and the struck-T variants (variant 4, the slanted strike, was chosen). |

**Coins:** one round coin with an open timer ring — **Ton (1)**, **Ten-ton (10)**, **Hundred-ton (100)**, light → forest = worth more.

Colours: lime `#C9F26B`, ink `#16210F`, leaf `#6FBF3B`, forest `#2F6B2A`.
